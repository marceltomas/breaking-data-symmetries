# Breaking Data Symmetry is Needed For Generalization in Feature Learning Kernels

Code for the the paper ["Breaking Data Symmetry is Needed For Generalization in Feature Learning Kernels
"](). 

This repository was built off of [this](https://github.com/nmallinar/rfm-grokking) base repository.

## Installation details

`pip install -r requirements.txt`

## Running the code

notebook + cli (main.py)

## Files Overview

agop_utils.py
utils.py
data.py
train_kernel.py
main.py
experiments.ipynb

## Preprocessing

pipelines for additive vs multiplicative vs abelian (different functions work on different representations/encodings)

For clarity and demonstration, preprocessing is handled per function rather than in a unified pipeline.
